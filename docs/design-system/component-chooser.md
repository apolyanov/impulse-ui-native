# Choose a library package

Read this index first; open only the relevant capability guide and recipe. All entries describe repository source, not a published-version guarantee.

| Need                                                             | Package                                                | Setup                                                                                                                                                                                                  |
| ---------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Reveal or collapse sections without changing screens.            | [accordion](capabilities/accordion.md)                 | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Group related media, copy and actions on a surface.              | [card](capabilities/card.md)                           | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Browse a finite horizontal collection with snapping.             | [carousel](capabilities/carousel.md)                   | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Show numeric series with interactive native charts.              | [charts](capabilities/charts.md)                       | ThemeProvider and GestureHandlerRootView. Install/configure Skia, Gesture Handler, Reanimated and Worklets peers.                                                                                      |
| Choose independent options or represent a mixed selection.       | [checkbox](capabilities/checkbox.md)                   | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Choose and edit a color inline.                                  | [color-picker](capabilities/color-picker.md)           | ThemeProvider and GestureHandlerRootView. Configure SVG, Gesture Handler, Reanimated and Worklets; no portal/overlay provider is needed.                                                               |
| Reuse state, timing and callback behavior in React.              | [core](capabilities/core.md)                           | React; native hooks also require React Native. No ThemeProvider.                                                                                                                                       |
| Coordinate loading, empty, error and content states.             | [data-state](capabilities/data-state.md)               | ThemeProvider; configure Reanimated and Worklets.                                                                                                                                                      |
| Pick a date, time, date-time or range.                           | [datetime](capabilities/datetime.md)                   | ThemeProvider, GestureHandlerRootView and SafeAreaProvider. PortalProvider with a stable PortalStore and a mounted PortalsHost; configure Gesture Handler, Reanimated and Worklets.                    |
| Send typed events between disconnected React consumers.          | [echo](capabilities/echo.md)                           | React; no visual provider.                                                                                                                                                                             |
| Connect an Axios API client to TanStack Query.                   | [endpoint](capabilities/endpoint.md)                   | Axios client and TanStack Query QueryClientProvider; install axios and @tanstack/react-query.                                                                                                          |
| Render long virtualized lists with known item layouts.           | [flat-list](capabilities/flat-list.md)                 | React and React Native. No ThemeProvider is required by this wrapper.                                                                                                                                  |
| Show a top or bottom gesture-dismissable sheet.                  | [flyout](capabilities/flyout.md)                       | ThemeProvider, GestureHandlerRootView and SafeAreaProvider; Reanimated/Worklets setup. Local portals additionally need PortalProvider/PortalsHost; registered sheets need OverlayProvider/OverlayHost. |
| Add a label, description and validation to a custom control.     | [form-field](capabilities/form-field.md)               | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Render a named SVG glyph with an explicit visual weight.         | [icon](capabilities/icon.md)                           | ThemeProvider and react-native-svg; use icon-catalog.md for exact entrypoints.                                                                                                                         |
| Show an icon on a noninteractive themed surface.                 | [icon-view](capabilities/icon-view.md)                 | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Enter single-line or multiline text.                             | [input](capabilities/input.md)                         | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Present rows with leading content, text and trailing actions.    | [list](capabilities/list.md)                           | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Request focused confirmation or show a compact dialog.           | [modal](capabilities/modal.md)                         | ThemeProvider and SafeAreaProvider; configure Reanimated/Worklets. Use PortalProvider/PortalsHost for local portals or OverlayProvider/OverlayHost for global registration.                            |
| Register and coordinate an application-wide overlay stack.       | [overlay](capabilities/overlay.md)                     | OverlayProvider with a stable OverlayStore and OverlayHost; visual overlays require their own peers/providers.                                                                                         |
| Navigate numbered pages with a controlled or uncontrolled page.  | [pagination](capabilities/pagination.md)               | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Anchor contextual actions or a tooltip to a trigger.             | [popover](capabilities/popover.md)                     | ThemeProvider, SafeAreaProvider, PortalProvider and a matching PortalsHost. Configure Reanimated/Worklets; see package peers.                                                                          |
| Render local content in a named host elsewhere in the tree.      | [portal](capabilities/portal.md)                       | PortalProvider with a stable PortalStore and PortalsHost. No ThemeProvider is needed for portal infrastructure.                                                                                        |
| Build layouts, typography, actions and custom field composition. | [primitives](capabilities/primitives.md)               | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Show determinate progress or ongoing activity.                   | [progress](capabilities/progress.md)                   | ThemeProvider; SVG, Reanimated and Worklets configured.                                                                                                                                                |
| Choose one option using application-owned grouping.              | [radio](capabilities/radio.md)                         | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Scroll content and reveal an initially selected measured child.  | [scroll-view](capabilities/scroll-view.md)             | React and React Native. No ThemeProvider is required by this wrapper.                                                                                                                                  |
| Choose one of a few adjacent options.                            | [segmented-control](capabilities/segmented-control.md) | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Choose one or multiple primitive values from a list.             | [select](capabilities/select.md)                       | ThemeProvider, GestureHandlerRootView and SafeAreaProvider. PortalProvider with stable PortalStore and PortalsHost; configure Gesture Handler, Reanimated and Worklets.                                |
| Represent the geometry of content while loading.                 | [skeleton](capabilities/skeleton.md)                   | ThemeProvider; Reanimated and Worklets configured.                                                                                                                                                     |
| Adjust one numeric value or a numeric range.                     | [slider](capabilities/slider.md)                       | ThemeProvider and GestureHandlerRootView; Gesture Handler, Reanimated and Worklets configured.                                                                                                         |
| Coordinate an application-owned multi-step flow.                 | [stepper](capabilities/stepper.md)                     | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Author native component examples and discover supported options. | [storybook](capabilities/storybook.md)                 | Install as a development dependency with the Storybook host; native preview uses the host providers.                                                                                                   |
| Toggle a persistent boolean setting.                             | [switch](capabilities/switch.md)                       | ThemeProvider; Reanimated and Worklets configured.                                                                                                                                                     |
| Switch between a few related content panels.                     | [tabs](capabilities/tabs.md)                           | ThemeProvider; install the owning package peer dependencies.                                                                                                                                           |
| Configure shared visual tokens and light/dark schemes.           | [theme](capabilities/theme.md)                         | ThemeProvider wraps themed components. Native host must load the configured fonts; default body family is Montserrat.                                                                                  |
| Show a transient status message with optional action.            | [toast](capabilities/toast.md)                         | ThemeProvider, SafeAreaProvider, OverlayProvider and OverlayHost; configure SVG, Reanimated and Worklets.                                                                                              |
| Consume most library packages through one application import.    | [toolkit](capabilities/toolkit.md)                     | Install toolkit and required peers for the features used; providers are still explicit.                                                                                                                |
