# @impulse-ui-native/list: capability guide

Present rows with leading content, text and trailing actions.

## Setup

- ThemeProvider; install the owning package peer dependencies.

## Capabilities

- Callable items renderer and Root/Item/Pressable/Leading/Content/Trailing parts.

## Boundaries and composition

- List does not implement selection state or virtualize a long dataset.
- Render arbitrary content into child-only parts; combine with FlatList for scale.

Exact contracts: [API reference](../api/list.md). Machine facts: [package JSON](list.json) or [full catalog](../capabilities.json).
